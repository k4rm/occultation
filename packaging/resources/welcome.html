Occultation

An audio plugin that turns light into sound — it watches an image source (camera, video file, network stream, FITS astrophotography stack, or a procedural star chart) and converts brightness into notes in real time.

This installer places:

  • VST3 → /Library/Audio/Plug-Ins/VST3
  • Audio Unit → /Library/Audio/Plug-Ins/Components
  • Standalone app → /Applications

Click Customize on the install step to choose a subset. Everything needed at runtime (OpenCV, FFmpeg) ships inside the bundles, so there is nothing else to install.

Occultation is an instrument that also emits MIDI: in a host, wire up both its MIDI input and its MIDI output to get notes back out of it.
